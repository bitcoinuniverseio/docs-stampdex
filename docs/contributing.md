# Contributing to this documentation

Corrections and improvements are welcome.

## How

- Found a mistake or a gap: open an
  [issue](https://github.com/bitcoinuniverseio/docs-stampdex/issues) that
  names the page and the problem.
- Have the fix: open a pull request that changes the page.

## Writing rules

- Short, plain sentences. One idea per sentence.
- State facts you can verify against the live product or API. If you
  cannot verify a claim, do not write it.
- Never use an em dash.
- Do not add hype words: no comprehensive, robust, seamless, world-class,
  revolutionary, or their relatives.
- Test every command before committing it, and show the expected result.
- A missing value is unknown, not zero. The docs follow the same honesty
  rule the product does.

## What does not belong here

- Credentials, keys, internal host names, private ports, or operator
  procedure. Private material lives in the private repositories.
- Documentation for features that are not live. Describe what works
  today.
